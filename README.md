# Student OOP Project

Учебная программа на Python для демонстрации объектно-ориентированного подхода.

## Возможности
- класс `Student` со свойствами имени, возраста и среднего балла;
- конструктор и методы установки/получения значений;
- вывод информации о студенте;
- определение словесной оценки;
- проверка корректности входных данных;
- несколько объектов и демонстрация изменения свойств.

## Запуск
Требуется Python 3.8 или новее.

```bash
python student.py
```
